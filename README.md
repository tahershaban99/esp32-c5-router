# راوتر ESP32-C5 فائق السرعة وإدارة الباقة والسرعات (5GHz Wi-Fi 6 NAPT Router)

مشروع فيرموير احترافي ومتكامل مبني خصيصاً على شريحة **ESP32-C5** من Espressif بمعمارية **32-bit RISC-V** بتردد **240MHz** مع نواة **ESP-IDF v6.x** وخطافات مخصصة لطبقة الشبكة **lwIP NAPT**. يقدم راوتر ومكرر إشارة واي فاي كامل على نطاق **5GHz Wi-Fi 6 (802.11ax)** فائق السرعة مع جدار ناري، محدد سرعة، تحكم بحصة الباقة، دعم وضع الألعاب VIP، وتصميم واجهة مستخدم زجاجي حديث (Glassmorphic UI) باللغة العربية مع دعم كامل للتيليجرام وإعادة التشغيل اليومي التلقائي.

---

## 🌟 الميزات والمواصفات الرئيسية

### 1. تقنية الجيل السادس 5GHz Wi-Fi 6 (802.11ax)
- **تردد 5GHz نقي**: خلو تام من تشويش شبكات الـ 2.4GHz وأفران الميكروويف وأجهزة البلوتوث المجاورة.
- **بروتوكول 802.11ax**: زمن استجابة شبه معدوم (Ultra-Low Latency & Ping) مخصص للألعاب والبث المباشر (Streaming).
- **كسب إشارة عالي**: متوافق مع هوائي الـ IPEX الخارجي الموصل ببوردة `NiceMCU ESP32-C5 Mini`.

### 2. معالجة أحادية النواة عالية الكفاءة (240MHz RISC-V Single Core)
- معمارية RISC-V حديثة بالكامل مترجمة بأحدث أدوات `riscv32-esp-elf` (GCC 15).
- خطاف توجيه الحزم (lwIP NAPT Hook) فائق السرعة في الـ IRAM مع جدول بحث مباشر `ip_lookup[256]` بفهرسة بالبايت الأخير لعنوان الـ IP لمطابقة فورية **O(1)** في دورة معالجة واحدة (1-cycle matching).
- جدولة ذكية لمهام الخلفية: منح أولوية معالجة فورية لحزم الإنترنت وتوجيه البيانات، مع تشغيل استعلامات التيليجرام بفاصل هادئ ومريح (3 ثوانٍ) لمنع أي تجميد للسرعة أثناء التحميل العالي.

### 3. واجهة مستخدم زجاجية حديثة مع محوّل سمات ديناميكي (Glassmorphic Design)
- **تصميم زجاجي عصري (Frosted Glass)** بتقنية `backdrop-filter: blur(20px)` وتدرجات ضوئية مريحة للعين.
- **شريط تبديل السمات الديناميكي**:
  - 🌅 **الغروب الكوني (Cosmic Sunset)**: خلفية فلكية داكنة مع لمسات متوهجة بألوان الغروب الدافئة ووردي نيون.
  - ⚡ **الأخضر السيبراني (Cyber Matrix)**: خلفية ماتركس خضراء مع توهج نيون إميرالد مستقبلي.
  - حفظ وتذكر السمة المفضلة تلقائياً عبر `localStorage`.
- رسم بياني مباشر لحركة البيانات وسرعة التحميل والرفع (HTML5 Canvas Real-Time Bandwidth Graph).
- نمطان لعرض الأجهزة: **بطاقات زجاجية تفاعلية (Cards View)** أو **جدول تفصيلي (Table View)**، متوافق 100% مع الهواتف الذكية.
- مؤشرات حية لعرض شارة **⚡ 5GHz Wi-Fi 6** وقناة البث وتردد المعالج 240MHz.

### 4. تنبيهات استهلاك الباقة التلقائية المتعددة عبر التيليجرام (Multi-Threshold Push Alerts)
- **تنبيهات الباقة الرئيسية وباقات الأجهزة الفردية**:
  - فحص مستمر لنسبة استهلاك الباقة الكلية للراوتر، وكذلك نسبة استهلاك كل جهاز له حصة محددة.
  - إرسال إشعار فوري واحترافي باللغة العربية عبر التيليجرام فور تجاوز كل حد من الحدود المحددة (مثال: `50%, 75%, 90%, 95%, 100%`).
  - عند وصول استهلاك أي جهاز إلى 100%، يتم إرسال تنبيه حظر تلقائي وإيقاف وصوله للإنترنت فوراً.
- **منع التكرار والإزعاج**: تتبع الحدود التي تم إطلاقها وتفعيلها مرة واحدة فقط لكل دورة فوترة، مع إعادة ضبطها تلقائياً عند تجديد الباقة أو تصفير العدادات.

### 5. بوت التيليجرام التفاعلي المباشر (Interactive Telegram Bot)
- مهمة FreeRTOS خلفية متوازنة بنظام **Long Polling (`getUpdates`)** المشفر عبر HTTPS/mbedTLS.
- يدعم مجموعة متكاملة من الأوامر والاستعلامات التفاعلية:
  - `🔹 /quota` أو `استهلاك` أو `باقي`: استعلام فوري عن رصيد باقة الراوتر الكلية، مع كشف استهلاك باقات الأجهزة المحددة.
  - `🔹 /devices` أو `أجهزة`: عرض الأجهزة المتصلة حالياً، سرعاتها اللحظية، باقاتها، سقوف السرعة وحالة الحظر.
  - `🔹 /speed` أو `سرعة`: قياس السرعة اللحظية للشبكة (تحميل ورفع) وحالة القناة 5GHz.
  - `🔹 /block [IP]` أو `حظر [IP]`: حظر جهاز متصل ومنعه من الإنترنت فوراً عبر lwIP NAPT.
  - `🔹 /unblock [IP]` أو `فك_حظر [IP]`: فك حظر الجهاز وإعادة وصول الإنترنت له فوراً.
  - `🔹 /status` أو `حالة`: تقرير مفصل عن حالة راوتر ESP32-C5، الذاكرة الحرة (RAM)، وتردد المعالج RISC-V.
  - `🔹 /ota` أو `تحديث`: عرض تفاصيل إصدار الفيرموير الحالي وقسم الإقلاع الثنائي OTA.
  - `🔹 /reboot` أو `ريستارت`: إعادة تشغيل الراوتر عن بُعد بعد حفظ العدادات بأمان.
  - `🔹 /help` أو `مساعدة`: عرض دليل الأوامر التفاعلية الكاملة.

### 6. إعادة التشغيل اليومي التلقائي (Scheduled Daily Auto-Reboot)
- مزامنة مستمرة للوقت عبر بروتوكول NTP العالمي (`pool.ntp.org`).
- ضبط موعد يومي لإعادة التشغيل (مثال: `03:00 AM`) مع دعم فروق التوقيت الزمني (Timezone).
- حفظ العدادات والبيانات في NVS وتفريغ الذاكرة المؤقتة تلقائياً قبل تشغيل أمر `esp_restart()`.

### 7. سعة اتصال مطورة وتحسين فائق للذاكرة (384KB SRAM Optimization)
- رفع حد أجهزة الـ SoftAP إلى **12 جهاز متصل في نفس الوقت** (`max_connection = 12`).
- جدول تتبع موسع L3 IP/MAC لـ **32 جهاز نشط تزامناً**.
- **Zero-RAM Web UI Serving**: الواجهة مضغوطة مسبقاً بتقنية Gzip ومخزنة في ذاكرة الفلاش `.rodata` وتُبث مباشرة برأس `Content-Encoding: gzip` بدون حجز أي بايت من الذاكرة العشوائية!
- **Chunked JSON Streaming**: بث الـ JSON في نهايات `/api/devices` و `/api/scan` باستخدام بافر على الـ Stack بدون `malloc`.
- زر استعادة ضبط المصنع المادي: الضغط المطول لمدة 10 ثوانٍ على زر **BOOT (GPIO 9)** في لوحة NiceMCU Mini لإعادة تعيين اسم المستخدم وكلمة المرور إلى `admin/admin`.

### 8. الترقية الهوائية الآمنة والذكية (Secure Over-The-Air OTA Updates)
- **نظام إقلاع مزدوج عالي الموثوقية (Dual-Bank OTA Partitioning)**: تقسيم الفلاش إلى بنكين متساويين (`ota_0` و `ota_1` بحجم 1.7 MB لكل منهما).
- **حماية كاملة من الأعطال (Anti-Rollback Protection)**: التحقق من صحة الفيرموير عند الإقلاع الأول، والتراجع التلقائي للنسخة السابقة العاملة في حال فشل الإقلاع.
- إمكانية التحديث المباشر برفع ملف الـ `.bin` من واجهة الويب أو التحديث السحابي التلقائي بضغطة زر.

## ⚡ كيفية البناء والحرق على البوردة (NiceMCU ESP32-C5 Mini)

### 1. البناء (Build):
افتح PowerShell في مجلد المشروع ونفّذ:
```powershell
.\build_firmware.ps1
```

### 2. الحرق على البوردة (Flash):
قم بتوصيل بوردة الـ ESP32-C5 بالكمبيوتر عبر كابل USB Type-C ونفّذ:
```powershell
.\flash_firmware.ps1 -Port COM3
```
*(استبدل COM3 برقم المنفذ التسلسلي الظاهر في إدارة الأجهزة Device Manager عندك)*.

> [!TIP]
> إذا توقفت أداة الحرق على رسالة `Connecting.....`:
> اضغط مع الاستمرار على زر **BOOT** على البوردة، ثم اضغط ضغطة سريعة واحدة على زر **RST**، ثم اترك زر **BOOT**؛ ستدخل البوردة في وضع التحميل (Download Mode) فوراً ويكتمل الحرق بنجاح.
