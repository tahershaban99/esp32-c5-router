📋 دليل الأوامر التفاعلية للبوت

يمكنك مراسلة البوت الخاص بك في التيليجرام بالأوامر التالية: • /quota أو استهلاك أو باقي : استعلام فوري عن باقة الراوتر واستهلاك باقات الأجهزة المحددة.
• /devices أو أجهزة : عرض الأجهزة المتصلة حالياً مع تفاصيل السرعة والكوتا وتحديد السرعة.
• /speed أو سرعة : قياس السرعة اللحظية للرفع والتحميل وحالة القناة 40MHz.
• /block [IP] أو حظر [IP] : حظر جهاز متصل ومنعه من الإنترنت فوراً عبر lwIP NAPT.
• /unblock [IP] أو فك_حظر [IP] : إلغاء حظر الجهاز وإعادة وصول الإنترنت له فوراً.
• /status أو حالة : تقرير شامل عن حالة الراوتر والذاكرة المتاحة وتردد المعالج.
• /ota أو تحديث : تفاصيل إصدار الفيرموير وقسم الإقلاع الثنائي OTA.
• /reboot أو ريستارت : إعادة تشغيل الراوتر عن بُعد بعد حفظ العدادات بأمان.
