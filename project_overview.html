  • ✔ أزرار Inline Keyboards تفاعلية لأصحاب الأجهزة المتعددة.
  • ✔ قناع رقمي (Bitmask) لمنع الإزعاج وتكرار التنبيهات.

إدارة السرعات والكوتا المتقدمة
  • ✔ محدد سرعة Token-Bucket عالي الدقة دون حجز ذاكرة (Zero-Heap).

  • ✔ تخصيص كوتا بالجيجابايت وحظر فوري عند الاستهلاك 100%.

  • ✔ تثبيت عنوان الـ IP للراوتر (Static IP) وللأجهزة المتصلة لمنع تضارب العناوين.
